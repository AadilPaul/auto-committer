# Auto Pusher
## Push your code to a repo with a single command.
- For simple and easy pushing, use this auto-pusher.
- An interactive model that lets you know what it's doing.
- Run with this one line of code in your bash terminal:
```bash
bash auto-committer/launch.sh # Wow! So easy and simple! How does @AadilPaul do it?
```
(Exact command will vary based on directory relative to project).
