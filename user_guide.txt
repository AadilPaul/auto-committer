Welcome to the autocommiter!
This autocommiter can be a very useful tool, however...
There are a few things you need to know.
    1. You must have git installed (This one's kinda obvious...), with bash version 4 or higher (test with 'bash --version')
    2. If you have another type of terminal, you cannot run this program on it. Use git bash.
    3. This is a very basic auto committer. It does not have a lot of features (for now).
    4. This application cannot handle branches and a lot of other things (again, for now).
    5. It only handles: git add ., git commit -m "", and git push. Please report any bugs you see.
Now that those are out of the way, here's the more fun stuff: 

HOW TO RUN THE CODE:
    To run the code, just type in "bash scripts/script.sh", or "bash scripts/faster_script.sh" in git bash. Then, you will be taken through the commit process.

WHAT EXACTLY DOES THIS CODE DO:
    This code runs through a series of commands to push your code to any repo. 
    The entire process is completely interactive.
    For faster pushing, use faster_script.sh. This model only asks for your commit message. 
    It adds everything using 'git add .', and automatically pushes to your repo. This means that it is less interactive.
    Use this model with caution.

SOME NOTES ABOUT THE PROCESS:
    It is best to have the scripts folder in the home directory of your repo. You do not need anything outside of scripts/.
    Other places will work, but this is to ensure that you aren't messing with directories for ten minutes (but maybe you're better than me).
    If the scripts folder is in the root directory of your repo, when it asks for directory, type in "./".
